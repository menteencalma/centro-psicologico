# Centro Psicológico Mente en Calma

Sitio web estático del Centro Psicológico Mente en Calma, preparado para GitHub Pages.

## Publicación

En **Settings → Pages**, elige **Deploy from a branch**, rama **main**, carpeta **/(root)**. La página se publicará en `https://menteencalma.github.io/centro-psicologico/`.

## Actualización

Edita `index.html`, `styles.css`, `app.js` y `assets/`. Los enlaces internos usan rutas relativas para funcionar bajo `/centro-psicologico/`. El carrito de terapia usa `localStorage` y prepara un mensaje para WhatsApp; no procesa pagos ni reserva citas automáticamente.
